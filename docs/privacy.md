# Taskify Privacy Statement & Network Inventory

Taskify is built from the ground up as a **fully offline, privacy-first task manager**. We believe your private spoken conversations, thoughts, plans, and task details belong entirely to you and should never leave your physical device.

---

## 1. Zero Network Interactions

Taskify compiles a strict **Network Interaction Inventory** containing exactly zero runtime remote operations:

- **No Remote Speech Recognition**: All audio captured via your microphone is transcribed locally using `vosk` or `faster-whisper`.
- **No Cloud LLM Processing**: Task extractions and Eisenhower classifications are performed locally via Ollama (using models running on your system like `phi4` or `gemma`) or via our rule-based `NLPBackend` regex system.
- **No Telemetry or Tracking**: The application does not collect usage stats, metrics, crash dumps, or run analytics trackers.
- **Zero Remote Dependencies**: The application does not download runtime assets. (The only remote network requests are initiated explicitly by the user when running `taskify download-model` to fetch voice packs).

---

## 2. Local File & Data Storage Inventory

All data generated by Taskify is stored in plain sight, locally on your machine. You can inspect, modify, back up, or delete it at any time.

### Database
- **Path**: `~/.local/share/taskify/taskify.db` (SQLite format)
- **Contents**: Stores capture sessions, transcribed speech text segments, task lists, and Eisenhower Matrix categories.

### Rotation Logs & Transcripts
- **Path**: `~/.local/share/taskify/logs/`
- **Markdown Logs (`YYYY-MM-DD.md`)**: A daily human-readable record of all conversations transcribed during that day.
- **JSON Lines Logs (`YYYY-MM-DD.json`)**: Machine-readable logs of session transcripts for debugging.
- **Application Diagnostics Log (`app.log`)**: Unified application operation logs (rotated automatically at 10 MB).

### Configuration Files
- **Default Package Configuration**: `src/taskify/config/config.default.toml`
- **User Preference Configuration overrides**: `~/.config/taskify/config.toml` (TOML format)
- **Contents**: Local audio rate, silence detection threshold, selected STT model parameters, and Ollama host server configurations.

### Local Machine Models
- **Path**: `~/.local/share/taskify/models/`
- **Contents**: Extracted local speech recognition models (`vosk` directories).
